# Επισήμανση Νομικών Ορισμών στην Ελληνική Νομοθεσία

Εντοπισμός νομικών ορισμών σε κείμενα ΦΕΚ με κανόνες (κανονικές εκφράσεις), βαθμολόγηση της αξιοπιστίας τους
και, προαιρετικά, θεματική κατηγοριοποίηση με το [KEVLAR](https://github.com/dhfbk/kevlar) (θησαυρός EuroVoc).
Τα αποτελέσματα εμφανίζονται σε διαδραστική εφαρμογή Streamlit.

Το έργο αναπτύχθηκε στο πλαίσιο της διπλωματικής εργασίας
«Επισήμανση Νομικών Ορισμών στην Ελληνική Νομοθεσία με Χρήση Συμβολικής Τεχνητής Νοημοσύνης».

## Γρήγορη εκκίνηση

Χρειάζεται Python 3 (η εφαρμογή δοκιμάστηκε με Python 3.13).

- **Windows:** διπλό κλικ στο `start.bat`
- **macOS / Linux:** `./start.sh`

Την πρώτη φορά δημιουργείται εικονικό περιβάλλον (`venv`) και εγκαθίστανται οι βιβλιοθήκες του `requirements.txt`.
Στη συνέχεια η εφαρμογή ανοίγει στον browser, στη διεύθυνση `http://localhost:8501`.

Χειροκίνητα:

```
python -m venv venv
venv\Scripts\python -m pip install -r requirements.txt      (Windows)
venv/bin/python -m pip install -r requirements.txt          (macOS / Linux)
venv\Scripts\python -m streamlit run ui.py
```

## Δεδομένα

### Βάση-παράδειγμα

Το αποθετήριο περιλαμβάνει τα αποτελέσματα της εργασίας στο `example/orismoi.db` (περίπου 40 MB):
15.187 ορισμοί από 1.429 φύλλα ΦΕΚ Τεύχους Α΄ (1992–2023), με βαθμό αξιοπιστίας και κατηγορίες EuroVoc.
Η εφαρμογή την εμφανίζει πάντα στο sidebar ως «(παράδειγμα)» και την ανοίγει αυτόματα, αν δεν υπάρχουν δικά
σου αποτελέσματα. Η βάση harvester από την οποία προήλθε δεν περιλαμβάνεται, οπότε η εφαρμογή δείχνει ένα
απόσπασμα από το κείμενο κάθε ορισμού.

### Φάκελος δεδομένων

Οι υπόλοιπες βάσεις δεδομένων δεν περιλαμβάνονται στο αποθετήριο. Η εφαρμογή τις αναζητά σε έναν **φάκελο
δεδομένων**:

1. τη μεταβλητή περιβάλλοντος `THESIS_DATA_DIR`, αν έχει οριστεί,
2. αλλιώς τον φάκελο που επιλέχθηκε από το sidebar της εφαρμογής (αποθηκεύεται στο τοπικό `settings.json`),
3. αλλιώς τον φάκελο `vasi` δίπλα στον φάκελο του έργου (`../vasi`).

Κάθε βάση SQLite (`.db`) του φακέλου αναγνωρίζεται αυτόματα:

- **Βάση harvester** (κείμενα ΦΕΚ): πίνακας `et` με τις στήλες `ID`, `fekNumber`, `fekEtos`, `nomosNum`,
  `nomosCategory` και `fekTEXT`. Κάθε γραμμή αντιστοιχεί σε ένα νομοθέτημα· το `fekTEXT` περιέχει το κείμενο του
  φύλλου ΦΕΚ στο οποίο δημοσιεύθηκε (νομοθετήματα του ίδιου φύλλου έχουν το ίδιο κείμενο).
- **Βάση αποτελεσμάτων**: πίνακας `definitions` (και, όπου υπάρχουν, `scores`, `categories`, `run_info`).

Η εφαρμογή ανοίγει πρώτα το `orismoi.db` του φακέλου δεδομένων, αν υπάρχει. Αλλιώς ανοίγει την πρώτη βάση
αποτελεσμάτων του φακέλου ή, αν δεν υπάρχει καμία, τη βάση-παράδειγμα. Όλες οι βάσεις αποτελεσμάτων επιλέγονται
από το sidebar, ώστε να είναι εύκολη η σύγκριση διαφορετικών εκτελέσεων.
Χωρίς βάση harvester η εφαρμογή λειτουργεί κανονικά, αλλά δείχνει μόνο ένα απόσπασμα του κειμένου κάθε ορισμού.

## Νέα ανάλυση

Από τη σελίδα **«🧪 Νέα ανάλυση»** επιλέγεται (ή ανεβαίνει) η βάση harvester και δίνεται όνομα για τη νέα βάση
αποτελεσμάτων. Η εκτέλεση γίνεται στο παρασκήνιο, με ένδειξη προόδου. Για πολύ μεγάλες βάσεις, είναι ταχύτερο
να αντιγραφεί το αρχείο απευθείας στον φάκελο δεδομένων αντί να ανέβει από τον browser.

Η ίδια ροή εκτελείται και από τη γραμμή εντολών:

```
python pipeline.py --source ../vasi/harvester.db --out ../vasi/orismoi_new.db
python pipeline.py --source ../vasi/harvester.db --out ../vasi/orismoi_new.db --categorize
python pipeline.py --out ../vasi/orismoi_new.db --only-categorize
```

Τα επιμέρους βήματα εκτελούνται και μεμονωμένα: `extract.py --source … --out …`,
`score.py --db …`, `category.py --db … [--api …]`.

## Κατηγοριοποίηση με το KEVLAR (προαιρετικά)

Η εξαγωγή και η βαθμολόγηση δεν χρειάζονται το KEVLAR. Για τις κατηγορίες EuroVoc, το KEVLAR πρέπει να τρέχει
τοπικά σε Docker. Σύμφωνα με τις οδηγίες του [αποθετηρίου του KEVLAR](https://github.com/dhfbk/kevlar):

```
git clone https://github.com/dhfbk/kevlar
cd kevlar
docker build --build-arg="LANGS=el" -t kevlar .
docker run -p 8080:80 kevlar
```

Με `LANGS=el` περιλαμβάνεται μόνο το ελληνικό μοντέλο· χωρίς την παράμετρο κατεβαίνουν και τα 24 μοντέλα
(πάνω από 50 GB). Η εφαρμογή ελέγχει αν το KEVLAR απαντά στο `http://localhost:8080` (η διεύθυνση αλλάζει από τη
σελίδα «Νέα ανάλυση»). Αν δεν απαντά, η κατηγοριοποίηση απενεργοποιείται και εμφανίζονται οδηγίες. Κατηγορίες
μπορούν να προστεθούν και αργότερα σε υπάρχοντα αποτελέσματα.

## Αρχεία

| Αρχείο | Ρόλος |
|---|---|
| `ui.py` | εφαρμογή Streamlit (επισκόπηση, περιήγηση, κατηγορίες, νέα ανάλυση) |
| `pipeline.py` | ολόκληρη η ροή: εξαγωγή → βαθμολόγηση → κατηγοριοποίηση |
| `extract.py` | εξαγωγή ορισμών με κανονικές εκφράσεις |
| `score.py` | βαθμός αξιοπιστίας κάθε ορισμού |
| `category.py` | κατηγοριοποίηση EuroVoc μέσω του KEVLAR |
| `directories.py` | φάκελος δεδομένων και προεπιλεγμένες διαδρομές |
| `example/orismoi.db` | βάση αποτελεσμάτων-παράδειγμα (η πληροφορία για την προέλευσή της βρίσκεται στον πίνακα `run_info`) |
| `KNOWN_ISSUES.md` | γνωστοί περιορισμοί και ιστορικό των αλλαγών στην εξαγωγή |
| `start.bat`, `start.sh` | εκκίνηση με ένα βήμα |
